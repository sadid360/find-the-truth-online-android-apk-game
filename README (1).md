# Find the Truth! Online 🔍

A fun two-player online Android game where friends challenge each other to find the one true statement.

বন্ধুর সঙ্গে অনলাইনে খেলার একটি মজার Android গেম। কয়েকটি স্টেটমেন্টের মধ্যে সত্যি মাত্র একটি—সেটি খুঁজে বের করতে পারবে কি?

## English

### Features

- **Two-player online rooms:** Create a room and share its six-digit code with a friend.
- **3 or 4 options:** The host chooses how many statements to play with; four is the default.
- **Adjustable timer:** Choose 20, 25, 30, 35 or 40 seconds. The default is 25 seconds for three options and 30 seconds for four.
- **Live chat and emoji reactions:** Chat and react while playing.
- **Math and brain mini-games:** Play while waiting for your friend to write their statements.
- **English and বাংলা:** Choose your preferred game language.

### Download and install

**Android 7.0 or later and an internet connection are required.**

[Download the latest APK](https://github.com/sadid360/find-the-truth-online-android-apk-game/releases/latest)

1. Download the APK from the latest release and open it to install.
2. If prompted, allow your browser or file manager to install apps from that source.
3. Ask your friend to install the same version.
4. One player creates a room and shares the code; the other joins using that code.

### How to play

1. The host selects the number of options and the timer.
2. The storyteller writes the statements and privately marks one as true.
3. The other player tries to find the truth before time runs out.
4. A correct guess earns the detective **2 points**. An incorrect guess or timeout earns the storyteller **2 points**.
5. Players alternate roles over four rounds; the highest score wins.

### Important notes

- This is a **debug APK**, not a Google Play Store release. Full testing on physical Android devices has not been completed.
- Online play depends on the Firebase project remaining active and within its usage limits.
- Rooms do not have passwords. Share the code only with people you trust and avoid sharing sensitive information in chat.
- If an older installed version has a different signing key, you may need to uninstall it first. Uninstalling removes the local guest identity and math-game history.
