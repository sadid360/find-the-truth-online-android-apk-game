# Find the Truth! Online

A fun two-player Android game where you challenge a friend to find the one true statement.

## Features
- Private online rooms
- Live chat and emoji reactions
- Math and brain mini-games
- English and Bengali

**Requirements:** Android 7.0+ and an internet connection.
